# University Club Management Portal

## Project Overview

The University Club Management Portal is a simple web application developed using Angular. It helps students explore university clubs, view upcoming events, and register their interest in joining clubs.

## Objectives

- Display information about university clubs.
- Show upcoming university events.
- Provide a student club registration form.
- Display university club contact information.
- Practice Angular components, routing, data binding, and forms.

## Technologies Used

- Angular
- TypeScript
- HTML
- CSS

## Main Features

1. **Home:** Welcome message and featured clubs.
2. **Clubs:** Information about Coding, Sports, Cultural, and Photography clubs.
3. **Events:** Event names, dates, venues, and descriptions.
4. **Join Club:** Student registration form with validation.
5. **Contact:** Contact information and a message form.

## How to Run the Project

1. Install Node.js and Angular CLI.
2. Download or clone this repository.
3. Open a terminal inside the project folder.
4. Run `npm install`.
5. Run `ng serve`.
6. Open `http://localhost:4200` in your browser.

## Testing

The project has 7 passing Angular tests across 6 test files.

The production build was also tested using `ng build`.

## Note

This project is developed for the Essentials of Web Programming laboratory. Registration and contact forms demonstrate frontend functionality; they do not save information to a backend database.
